# bell-schedule-mock
static json, served to test a clock-extension before the real API goes live.

It is our own 'mock-up' of what the API should look like from the school district. It is loosely based on the calendar, not guaranteed to be correct, and certainly is not going to update for 2-hour delays. But it gives a looks-close target to use while the school district gets their API sorted.

>[!TIP]
>This repo will be taken down once the *real* data goes live.
